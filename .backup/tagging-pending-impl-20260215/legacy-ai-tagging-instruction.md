## 実行順序（この順で必ず全部やる。1つでも抜かしたら未完了）

| 順番 | やること | 抜かしたら |
|------|----------|------------|
| 0 | **all-tags（s, a, b）を取得し、タグ付けの入力に必ず含める**（後述「参照先」を参照） | S/A の判別ができない、新規タグを付けがちになる |
| 1 | workIds で `npx tsx scripts/fetch-works-for-ai.ts <workIds>` を実行し、作品データを取得する | タグ付けできない |
| 2 | 取得した JSON を使って各作品にタグ付けし、後述の JSON 形式で出力する | 出力がない |
| 3 | **返した JSON 全文を会話に貼り付ける** | 私が確認できない |
| 4 | **返した JSON を `data/chatgpt-export/` に保存する**（例: cursor-analysis-untagged-10-batch1.json） | チェック待ちに並ばない |
| 5 | **`npx tsx scripts/apply-cursor-legacy-ai-batch.ts 保存したファイル名.json` を実行する** | **チェック待ちに並ばない。= 未完了** |

**完了の定義**: 上記 6 つ（0〜5）をすべて終えたときだけ完了。**4 と 5 をやらないと対象作品はチェック待ちに並ばない。JSON を返すだけでは完了ではない。**
