# タグチェック指示書 API2（提案・5件バッチ版）

**この指示書だけを読んで実行する。別ファイルは参照しない。**

API1 で「人間による確認が必要」と判断された作品について、**追加提案**（tagChanges.added, tagSuggestions.newProposal）のみを出力する。**複数作品（最大5件）をまとめて処理する。**

---

## ゴール

**タイトル＋コメントから得られる軸**がタグで十分に表現されていない場合、allTags から追加すべきタグを提案する。リストにない場合は新規提案を1個まで出す。**各作品について results 配列で返す。**

---

## 目的

**タイトル＋コメントから得られる作品の軸**が、タグで適切に表現されているかを見る（API1 と同じ観点）。  
API1 で「軸の表現が不足」と判断された作品について、**既存タグリスト（allTags）から軸を補う適切な語を選んで提案**する。

**チェック・提案対象**: officialTags（既存S）・additionalSTags（追加S）・derivedTags（A/B）の現状を踏まえ、軸を補う追加を提案。**officialTags（既存S・DMM由来）は削除の対象にしない。**

**優先順位**: 作品の軸において、**優先順位が高い要素**がタグに含まれていなければ追加提案する。優先順位が高い要素がすでに入っていれば十分。細分化レベルの不足は提案不要。

---

## 【重要】allTags の全探索

**allTags の s / a / b をすべて確認すること。** タイトルから連想できる代表的タグだけを見て打ち切らない。  
数百件・数千件あっても、**全件を探索**して「軸を適切に表現する」のに最適な語を選ぶ。

---

## 入力

- **allTags**: s（公式タグ）, a（Aランク付加）, b（Bランク付加）の配列
- **works**: 作品データの配列（1〜5件）。各要素に workId, title, commentText, officialTags, additionalSTags, derivedTags, characterName, **api1Issues**, **api1CheckReasoning** が含まれる

---

## 【重要】API1 の api1Issues に従う

**api1Issues が渡されている場合、その指摘に必ず従う。**
- issues に挙がった不足を補うタグを added に含める（allTags から選ぶ）
- issues を無視して独自の判断で別の提案をしない
- issues が空でない限り、少なくとも1件は issues に対応する提案を出す

---

## ルール

1. **tagChanges.added**: allTags の s/a/b から選ぶ。**最大2個まで**。officialTags・additionalSTags に既に同じ語が含まれていないか確認してから追加。軸が十分に表れている作品には追加不要（0個でよい）。**officialTags（既存S・DMM由来）は削除の対象にしない。**
2. **tagSuggestions.newProposal**: **allTags に該当語が無い場合のみ**1個まで。リストを全探索して本当に無いことを確認してから提案。**タグ名のみ。2〜10文字程度の簡潔な語。括弧・説明・理由を付けない。**（例: 「二次創作」のみ。×「二次創作（ドラゴンボール） — 原作キャラを用いた派生作品のため」）
3. **有名タグリスト（使用禁止）**: タグ付け用のルールであり、**チェックには適用しない**。軸を補うのに適切なら added に含めてよい。

---

## 出力形式

**results は works と同じ順序・同じ件数で返す。省略不可。**

```json
{
  "results": [
    {
      "workId": "d_xxxxxx",
      "tagChanges": {
        "added": ["追加すべきタグ1", "追加すべきタグ2"],
        "removed": []
      },
      "tagSuggestions": {
        "newProposal": "タグ名のみ。無ければ省略可"
      }
    }
  ]
}
```

- **added**: 最大2個まで。allTags を探索し、軸を補うのに最適な語を選ぶ。すでに軸が十分なら0個でよい。
- **newProposal**: allTags に無い場合のみ。**タグ名のみ**（2〜10文字程度）。括弧・説明・理由を付けない。無ければ tagSuggestions を省略可。

---

**出力はJSON形式のみ。説明文やマークダウンは不要。レスポンス本文は valid JSON 1件のみ。**
