# バックログ（★☆☆）：推薦・購買・未タグ

本編の「当てる」体験と拡散が十分に固まってから着手する想定の項目です。

## 推薦モード・購買導線

- 推薦は本編の付図として位置づける（ロードマップ前提）。
- 着手タイミングの目安: 有名帯の実プレイ検証と X 小規模テストで「当たる」が外からも説明できるようになったあと。
- 検討ネタ: 結果直後の FANZA 導線の優先度、マッチ率表示の見せ方、`RecommendMode` 完了時のシェア文言との整合。

## 未タグ約3万件

- データ資産として継続的に削る。アルゴリズムよりタグ付けオペの比重が高い。
- 着手タイミングの目安: 人気帯のタグ精度が頭打ちになってから、または週次バッチで少しずつ。
