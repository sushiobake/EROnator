# 推薦モード 内容まとめ（実装前 doc）

実装の現状と、これから詰める「本題」を整理した doc。  
詳細仕様は `recommend-mode-spec.md` を参照。

---

## 1. 概要・位置づけ

- **推薦モード**＝稲荷さんに同人誌を「推薦してもらう」おまけモード。ゲーム体験として楽しめる程度に実装する。
- プレイモードとの関係: 「当てられなかった人」への救済・リピーター獲得・FANZA クリック機会の補完。
- プレイモードで使っている **Stage・背景・白板・キャラ・質問→thinking→次** の流れを共通化し、変えるのは **質問文言・答え方・白板サイズ** に限定する（spec 方針）。

---

## 2. 現状の実装（ここまででやったこと）

### 2.1 ユーザーフロー

| ステップ | 内容 |
|----------|------|
| 入口 | トップ画面の「こんな作品なんてどう？」から推薦モードへ。 |
| ① 質問 | Stage で「好みを教えて」＋ **1問だけ**（雰囲気はどれが好き？ 甘め / 激しめ / 切なめ）。 |
| ② thinking | 「あなたにぴったりの作品を探しているわ…」表示。 |
| ③ 結果 | 最大 **10作品** を表示。 |

※ 現状は **表面上だけ**: 1問固定（3択）→ thinking → 結果。質問の内部ロジック（タグ絞り・動的10タグ・好き嫌い集計）は未実装。

### 2.2 API

- **POST /api/recommend**
  -  body: `{ tagKeys: string[] }`（現状は空配列で「全作品から人気・レビューでソート」）。
  - レスポンス: `{ success, recommendedWorks[], totalMatched }`。最大10作品。各作品に `matchRate` を含む。
- アルゴリズム（現状）: `tagKeys` が空のときは gameRegistered 作品を人気順＋レビューでスコアし、上位10件を返す。`tagKeys` ありのときはタグ一致度・人気・レビューをスコアに組み合わせて上位10件。

### 2.3 結果表示（PC）

- **レイアウト**: 横 **5列 × 2行**（1行目5作品・2行目5作品）。おすすめのカードUIを流用。
- **カード**: 幅 1.34倍（ベース 0.8 スケール）、表紙は 4:3 横長、タイトル2行まで、似てる度・読んでみるリンク。
- **カード間**: 横の隙間のみ 1.5倍（columnGap）。
- **ボタン**: 「もう１度妄想する」→ **トップ画面に戻る**。「Xでポストする」で共有。

### 2.4 結果表示（スマホ）

- **キャンバスなしレイアウト**: 白板・キャラ・ロゴは出さない。背景のみ同じ。
- **構成**: 上から (1) 見出し「こんな作品なんてどう？」 (2) おすすめ10件の縦リスト（`MobileWorkCardHorizontal`） (3) 一番下に「もう１度妄想する」「Xでポストする」。
- 「もう１度妄想する」→ トップ画面に戻る。

### 2.5 おすすめ（本編）との共通化

- 結果のカード見た目・表紙アスペクト・似てる度表示は本編のおすすめを流用。
- スマホの「おすすめ」はボタンを「もう１度妄想する」と「Xでポストする」の横並び（右に X）に統一済み。

## 3. 本題：これから詰める内容（spec との対応）

実装する前に doc で固めたいのは次の3つ（`recommend-mode-spec.md` の ①②③ に対応）。

### ① おすすめ選定の仕方（アルゴリズム）

- **確定方針**: Sタグによる選定は本編と同様。**有名か無名か**は推薦専用の軸（人気度・露出の調整）。ハード/ソフトコンフィムは推薦では使わない。
- **現状**: API は「タグ一致度 ＋ 人気 ＋ レビュー」でスコアし最大10件。タグ未選択時は人気・レビューのみ。
- **今後**: 有名/無名のウェイト・「少し意外を混ぜる」の有無などを必要に応じて詰める。

### ② 質問と回答（推薦の「中身」）

- **制約**: 最大10問。「推薦してもらう体験」を損なわない形で設計。
- **設計案（spec に記載）**:
  - **前半（Q1〜Q3）**: 方向性の3択（雰囲気 / 何にこだわる / 知名度）→ タグプールを 646 → 100〜150 に絞る。
  - **中盤**: メジャータグ10個を提示 → 好き/嫌い/無関心（2〜3問）。
  - **後半**: 中盤で「好き」を選んだタグが付いている**作品群が持つタグ**のうち未提示を10個提示（共起ランキングではなく作品群ドリルダウン）。
- **実装方針**: まず **表面だけ**（Stage・1問・thinking・結果）を実装済み。②の内部（タグプール絞り・動的10タグ・好き嫌い集計・作品群ドリルダウン）は**あとから**実装する。

### ③ 結果の表示

- **確定**: 最大10作品。レイアウトは **5列×2行**（PC）・スマホはキャンバスなしで縦リスト＋ボタン。本編「おすすめ」のUIを流用。
- 現状の表示仕様（カードサイズ・表紙4:3・タイトル2行・ボタン配置）は「最適解」として一度固定。
