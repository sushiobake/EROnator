# サービス評価レポート — ERONATOR 現状診断

2026-02-27 作成。Opus による包括的評価。
目標に対する現在地、ギャップ、達成に必要な施策を整理する。

---

## 目標（再掲）

1. **アキネイターのように、メジャー作品は少ない質問数で当てられ、マイナー作品は質問数は多くなるが当てられる**
2. **達成感とともに、共有したり、購入したりしたくなるようなサービスになる**
3. **結果的にアダルトアフィリエイトとして成功する**

---

## 評価 1: アキネイター型ゲーム体験

### 判定: ◎ メジャー作品 / △ マイナー作品

### メジャー作品（pop35+）— ほぼ達成

| 指標 | 目標水準 | 現状 | 判定 |
|------|---------|------|------|
| 成功率（amb.1） | 95%+ | **96%** | ◎ |
| 成功率（amb.3） | 85%+ | **97%** | ◎ |
| 平均質問数 | 15 問以内 | **14.2Q**（amb.1） | ◎ |
| 15 問以内率 | 70%+ | **81%**（amb.1） | ◎ |

アキネイターの有名キャラクターと同等のパフォーマンス。
pop35+ = レビュー数が多く、FANZA で認知度のある作品。プレイヤーの多数派はこの層を思い浮かべるため、「第一印象」として十分に良い体験を提供できる。

### 中堅作品（pop15-34）— 達成

| 指標 | 目標水準 | 現状 | 判定 |
|------|---------|------|------|
| 成功率（amb.1） | 90%+ | **98%** | ◎ |
| 成功率（amb.3） | 80%+ | **93%** | ◎ |
| 平均質問数 | 20 問以内 | **15.2Q / 20.7Q** | ◎/○ |

### マイナー作品（pop0-14）— 課題あり

| 指標 | 目標水準 | 現状 | 判定 |
|------|---------|------|------|
| 成功率（amb.1） | 85%+ | **73%** | △ |
| 成功率（amb.3） | 65%+ | **52%** | △ |
| 平均質問数 | 30 問以内 | **17.3Q / 22.4Q** | ○ |

成功する場合の質問数は問題ないが、**成功率自体が低い。**

- 構造的失敗（タグで区別不可能な作品）が ~6% 残る
- アキネイターでもマイナーキャラの成功率は低いため、ある程度は許容される
- ただし「当てられない」が頻発すると体験が損なわれる

### ギャップを埋めるために必要なこと

| 施策 | 期待効果 | 優先度 |
|------|---------|--------|
| titleReadingInitial 全作品追加 | 構造的失敗 6% → 3% | 高 |
| 問題作品のタグ修正 | 3% → 1% | 中（10,000 件後） |
| 質問数の動的延長 | ノイズ駆動失敗を救済 | ✅ 実装済み |
| フェーズ別イプシロン | ノイズ耐性向上 | ✅ 実装済み |

**結論**: メジャー作品は完成レベル。マイナー作品は titleReadingInitial + タグ修正で「当てられる確率」を底上げする余地がある。10,000 件到達後のタグ修正で 1% 目標を目指す。

## 評価 2: 達成感・共有・購入意欲

### 判定: △ 基盤はあるが演出と導線が不足

### 2-1. 達成感

| 要素 | 現状 | 判定 |
|------|------|------|
| 正解した瞬間の演出 | Success 画面に作品表示 | ○ |
| 「近づいている」感覚 | 「考え中…」固定テキスト | **✗ 未実装** |
| 質問の面白さ | Special Question で多様化 | ○ |
| 失敗時の救済感 | 候補リスト表示 + 自由入力 | ○ |

**最大のギャップ: 「近づいている」演出がない。**

アキネイターの魅力の半分は「だんだん当たりそうになる緊張感」。現在は質問中ずっと同じ「考え中…」で、プレイヤーに進捗が伝わらない。

effectiveCandidates に基づく段階的リアクション（キャラ表情変化 + テキスト変化）を入れるだけで、体験が劇的に変わる。**本番公開前に必須の施策。**

### 2-2. 共有意欲

| 要素 | 現状 | 判定 |
|------|------|------|
| X 投稿ボタン | ✅ 実装済み | ○ |
| 投稿テキスト | 作品タイトルを含む | △（成人向けタイトルは共有しにくい） |
| OG 画像 | **✗ 未実装** | ✗ |
| 他 SNS 対応 | X のみ | △ |

**最大のギャップ: OG 画像がない。**

Twitter/X で URL を共有したときに画像カードが出ないと、クリック率が 2-3 倍違う。動的 OG 画像（`@vercel/og`）で「○○問で当てた！」のカードを生成するだけで拡散力が大幅に上がる。

**作品名を出さないデフォルト設定**は正しい判断。成人向けコンテンツの共有における「恥ずかしさ」のハードルを下げつつ、「何問で当てたか」の自慢要素で共有動機を作る。

### 2-3. 購入意欲

| 要素 | 現状 | 判定 |
|------|------|------|
| アフィリエイトリンク | ✅ FANZA 連携済み | ○ |
| CTA ボタン | ExternalLink コンポーネント | △（目立たない） |
| レビュー情報表示 | DB にあるが非表示 | ✗ |
| おすすめの理由 | 「似てる度」のみ | △ |
| おすすめ表示 | 正解後に 5 件表示 | ○ |

**購入導線は「機能的には完成」だが「訴求力が弱い」。**

レビュー情報（★ と件数）の表示は、EC サイトのコンバージョンにおける基本中の基本。DB に `reviewAverage` と `reviewCount` があるのに表示していないのはもったいない。

CTA ボタンの文言とデザインも「FANZA で見る」より「今すぐ読む」「サンプルを見る」の方が行動を促す。

## 評価 3: アフィリエイト事業としての成功可能性

### 判定: ○ 成功の要素は揃いつつある

### 収益モデルの構造

```
ユーザー流入 → ゲームプレイ → 正解/推薦 → FANZA クリック → 購入 → 報酬
```

各ステップの評価:

| ステップ | 現状 | ボトルネック度 |
|----------|------|---------------|
| **流入** | ほぼゼロ（β 版） | ★★★（最大のボトルネック） |
| **プレイ継続** | 体験は成立している | ★☆☆ |
| **正解到達** | 83-91% | ★☆☆ |
| **FANZA クリック** | リンクあり、追跡あり | ★★☆（CTA 改善で向上余地） |
| **購入転換** | FANZA 側の問題 | ★☆☆（コントロール外） |

**流入が最大のボトルネック。** サービスの質をいくら上げても、人が来なければ収益はゼロ。

### 流入を生む施策の評価

| 施策 | 潜在インパクト | 実装コスト | 優先度 |
|------|---------------|-----------|--------|
| **OG 画像 + X 投稿改善** | 高（共有のハードル低下 → 自然拡散） | 低 | ★★★ |
| **配信者モード** | 極高（1 配信 = 数千〜数万リーチ） | 中 | ★★★ |
| **推薦モード** | 中（リピーター獲得 + クリック増） | 中 | ★★☆ |
| **SEO** | 低（成人向けは SEO 効きにくい） | — | ★☆☆ |
| **note/SNS 発信** | 中（開発ストーリーで認知） | 低 | ★★☆ |

**配信者モードが最もレバレッジが高い。** 一人の中堅 VTuber や配信者がプレイするだけで、数千人が一度にサービスを知る。成人向けコンテンツは配信者の間で「ネタ」として使われやすく、配信者モード（露骨な表現を隠す）があれば使いやすい。

### 競合優位性

| 要素 | 評価 |
|------|------|
| 「アキネイター × 成人向け」の独自性 | ◎ 類似サービスなし |
| 技術的参入障壁 | ○ タグ付け + アルゴリズムの蓄積 |
| FANZA 依存リスク | △ API 停止や規約変更の可能性 |
| スケーラビリティ | ○ 作品追加は自動化済み |
| ネットワーク効果 | △ プレイデータで改善できるが限定的 |

**「ニッチ × エンタメ × 成人向け」の組み合わせは、大手が参入しにくい領域。** FANZA 自身が作っても「ゲーム体験」の作り込みではこのプロジェクトが先行している。

## 総合スコアカード

| 目標 | 達成度 | 残タスク |
|------|--------|---------|
| メジャー作品を少ない質問で当てる | **90%** | ほぼ完了。pop35+ は完成レベル |
| マイナー作品を当てる | **60%** | titleReadingInitial + タグ修正で 80% へ |
| 達成感の演出 | **50%** | 「近づいている」演出が必須 |
| 共有したくなる | **40%** | OG 画像 + 投稿テキスト改善 |
| 購入したくなる | **55%** | CTA 改善 + レビュー表示 |
| アフィリエイト事業として成立 | **30%** | 流入がゼロ。配信者モード + 拡散施策が鍵 |

### 全体評価

**「ゲームとして機能する」段階は超えた。「サービスとして人を呼べる」段階に入りつつある。**

技術的な基盤（アルゴリズム、DB、管理画面、パイプライン）は β 版としては十分に整っている。ここからの勝負は「体験の磨き込み」と「人を呼ぶ仕組み」。

具体的には:

1. **「近づいている」演出** — ゲーム体験の決定的な差別化要因。実装コスト低、効果大。
2. **OG 画像 + 配信者モード** — 流入のゼロを突破する 2 つの柱。
3. **CTA + レビュー表示** — 流入した人を確実に収益に変換する。

この 3 つが揃えば、「1 人がプレイ → 共有 → 数人が来る → その数人が共有 → …」の自然増殖ループが回り始める可能性がある。

**アキネイターの 1/10 規模（月間 UU 数万）は、配信者 1-2 人のバズがあれば到達しうる数字。** そのための「受け皿」を整えることが、今の最優先事項。

**差がついているのは「体験の演出」と「拡散の仕組み」。** ここが本番公開までに埋めるべきギャップ。
