# X（Twitter）小規模テスト配信の手順

**目的:** 本格拡散の前に、「有名作品で当てられるか」を外から証明し、反応と精度を材料に「まだ広げない／広げる」を判断する。

## 事前条件

- [VERIFY-top100-hit-rate.md](./VERIFY-top100-hit-rate.md) で、自分が信じられる有名帯の挙動を一通り確認済みであること
- 利用規約・表現（R18・リンク先）に抵触しない投稿文であること

## 手順

1. **対象作品を 1〜3 本に絞る**（本当に有名で、タグが厚いものを優先）
2. **投稿案を 2 パターン**用意する  
   - A: 「この作品を ○ 問で当てられるか挑戦」＋サイト URL  
   - B: 自分のプレイ結果スクショ（成功時の保存画像）＋短いコメント
3. **公式アカウント（例: @eronator_jp）または個人アカウント**から投稿（最初はリプ欄が荒れにくい時間帯でもよい）
4. **48〜72 時間**様子を見る: インプレッション、リプの質、「当たらなかった」報告の有無
5. **記録:** 日付・投稿 URL・反応メモ・自分が裏で再現プレイした問数

## 判断の目安

- **当てられない報告が多い:** まず検証ドキュメントに戻り、作品・設定を直してから再テスト
- **当たった楽しさが中心:** 同じフォーマットで週 1 回程度まで拡大し、プレイ履歴（管理画面）で離脱・FAIL の比率を監視

## 注意

- 作品名・サムネは配信規約・Xポリシーに注意（必要なら伏字・モザイク保存を使う）
- アフィリエイト URL を直接貼るより、**ゲーム URL への誘導**を主にする方が目的に合う
