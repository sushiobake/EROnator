# Phase0 タグ付け指示書（10件バッチ版）

**この指示書だけを読んで実行する。別ファイルは参照しない。**

あなたは同人誌・エロ漫画に詳しい。次の**複数作品（最大10件）**について、タイトルとコメントからタグを付け、指定のJSON形式で返す。

---

## ゴール

各作品に additionalSTags・aTags・bTags・characterName を付与する。**新規タグは禁止。** すべて allTags の s / a / b から選ぶ。

---

## 絶対原則

- **語彙**: allTags の `s`（公式）と `a`/`b`（A/B）のみ使用。**新規タグ禁止。** C ランクは使わない。
- **additionalSTags**: `s` に存在する語のみ。`s` に無い語は aTags/bTags へ。
- **重複を避ける**: 複合タグ1つで足りるなら「人妻幼馴染」だけ。同義語は1つに絞る。
- **根拠がなければ付けない**: 曖昧な根拠でタグを付けるより、0個の方がよい。

---

## 毎作品で必ず行うこと

1. **タイトルを必ず読む** … タイトルに含まれる語（合宿、催眠、JK、人妻、総集編 など）は必ずタグ候補に。
2. **キャラタグ（characterName）** … commentText に登場人物の名前があれば代表1人を入れる。なければ `null`。作品タイトルはキャラ名ではない。
3. **シリーズ系** … タイトルに数字・「続編」「総集編」「編」があれば、シリーズ系タグを1つ付ける（allTags の s に「シリーズもの」「ベスト・総集編」等があるか確認）。

---

## 入力（works 配列・各要素）

- **workId**: 作品ID
- **title**: タイトル
- **commentText**: 作品コメント（あらすじ等）
- **officialTags**: 既存S（DMM由来）の表示名の配列
- **allTags**: `{ s: 公式タグ[], a: Aランク[], b: Bランク[] }` 参照用

---

## タグ付けの手順

### ステップ1: 既存Sを確認

officialTags は「前提」。追加タグはこれ以外から選ぶ。

### ステップ2: タイトルからタグ候補

タイトルに出ている語を allTags で照合。`s` に在る → additionalSTags。`s` に無く `a`/`b` に在る → aTags/bTags。

### ステップ3: コメントから補足

commentText の**明記**されている特徴で、officialTags に無いものを1〜2個追加。推測禁止。

### 付けてよい / 付けてはいけない

- **付けてよい**: タイトル・あらすじに明記。主軸・差別化になる語を優先。
- **付けてはいけない**: メタ情報だけ、汎用語、曖昧・広義すぎるタグ、allTags に無い語。

---

## 出力形式

**results は works と同じ順序・同じ件数で返す。省略不可。**

```json
{
  "results": [
    {
      "workId": "d_xxxxxx",
      "title": "作品タイトル",
      "additionalSTags": ["公式タグの表示名"],
      "aTags": ["Aタグ1", "Aタグ2"],
      "bTags": ["Bタグ1"],
      "characterName": "キャラ名",
      "taggingReasoning": {
        "タイトルから": "1行で。",
        "各タグ根拠": "1行で。",
        "キャラ": "1行で。"
      }
    }
  ]
}
```

- **additionalSTags**: allTags.s から。既に officialTags にある語は含めない。
- **aTags** / **bTags**: allTags.a / allTags.b から。最大3個程度。既に officialTags・additionalSTags にある語は含めない。
- **characterName**: 登場人物名が明記されていれば代表1人。なければ `null`。
- **taggingReasoning**: 各項目1行以内。長文禁止。

---

**出力はJSON形式のみ。説明文やマークダウンは不要。レスポンス本文は valid JSON 1件のみ。**
