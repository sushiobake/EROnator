## Part A：相談と答えのまとめ（実装の指針）

### 私の方針（相談内容）

#### 質問の流れ

1. **最初の2問**
   - **Q1**: それは有名？ → 有名 / 無名 / 中間
   - **Q2**: 何を重要視？ → ストーリー / プレイ / キャラクター（**優先順位をつける**）

2. **そのあと（2～3回）**
   - Q2の結果に基づき、そのカテゴリの「**有名なタグ**」を表示（例: ストーリーなら 寝取り・NTR、学園もの、辱め、ラブラブ… など）。
   - 10個 or 20個程度。**複数選択可・選択しなくても可**。
   - 「すべて選択したら次へ」で 2～3 回繰り返す。

3. **無名タグの選択（2～3回）**
   - 選んだ「有名タグ」に**近い「無名タグ」**を選別して表示。
   - 同様に 10個 or 20個ずつ表示し、そこから選択。2～3回程度。

4. **優先2位のカテゴリ**
   - 優先順位2番目のカテゴリでも、同様に「有名タグ → 無名タグ」で絞る。
   - 質問数に余裕があればやる、という考え方。

#### 問題点1：全タグをカテゴリ分けすべきか

- 現状: ストーリー / プレイ / キャラ / その他 / 未分類。
- 有名タグ約100個は手動で分けたいが、**全部は面倒**。
- **問い**: 有名タグだけ手動で付けて、無名タグは「選ばれたタグとの関連性」だけで回せるか？

#### 問題点2：「特に重要視」チェック

- 1画面（1質問）につき**1個だけ**チェック可能にしたい。
- 結果表示のためのフラグとして使う。

#### 問題点3：結果の優先順位

1. 特に重要視をつけた**無名**タグ  
2. 特に重要視をつけた**有名**タグ  
3. 選択した**無名**タグ  
4. 選択した**有名**タグ  

#### 答え（結論）

- **「有名タグ → 関連する無名タグ」はできる。**  
  選んだ有名タグのどれかを持つ作品群 → その作品が持つ他タグを集計・出現頻度順 → 既提示を除外 → 残りが関連無名タグ。
- **全タグのカテゴリ分けは不要。** 有名約100タグだけ手動でストーリー/プレイ/キャラに分類。無名は「作品共有」で動的に引き出す。
- **特に重要視**: 1画面1個・排他。通常選択＝チェック、重要視＝星 or ハート。
- **結果スコア例**: 特に重要視=3.0、通常選択=1.0、無名タグは重み×1.5。作品スコア＝Σ(タグ重み)。
- **全体フロー（5ページ案）**: 1=有名/無名/中間+優先順位 → 2=優先1位の有名タグ20個 → 3=関連無名タグ20個 → 4=優先2位の有名タグ20個 → 5=結果表示。

### ここまでのポイント（保持する情報）

- **有名タグが合計60個**は並ぶ（優先1位 20+20、優先2位 20）。
- **前半の取得は最大9個**（各質問で最大3個 × 3問）。
- プレイヤーが選んだタグを**ちゃんと保持する**。
  - **カテゴリ**（ストーリー/プレイ/キャラのどれの質問で選んだか）
  - **「特に重要」チェック**の有無
- これらの情報があれば、後半の質問（無名タグの提示）に入っていける。

---

### ④ 後半（質問4～6）：無名タグの提示

ここまでの60タグから**選ばれたタグ**に、次のルールで**優先順位**をつける（後半のアルゴリズムで使う順序）。

1. **重要チェックがついたタグ**（優先順位は無視）→ **最大3個**
2. **（最初の質問で）優先順位が1のカテゴリ**で選んだタグ
3. **優先順位が2のカテゴリ**で選んだタグ

※ 取得が0個の場合などは、例外としてあとから措置を検討する。

**質問4・質問5・質問6**

- 文言: いったん**同じ**でよい（例: 「この中に欲しい特徴はある？ 3つまで選んで！ 特に重要なら1つだけチェックして！」など）。
- やること: **選ばれた有名タグ（上記優先順位）に基づいて導かれる無名タグ**を、**上位から20個ずつ**表示する。これを**3回繰り返す** → **合計60個の無名タグ**を表記する（質問4で20個、質問5で20個、質問6で20個）。
- 各質問でも「3つまで選択」「特に重要1つ」＋「これでok」「この中にはない」とする。

**アルゴリズム（無名タグの導出）**

- 内容: 相談まとめの通り。**選んだ有名タグのどれかを持つ作品群** → その作品が持つ**他タグ**を集計 → **既に提示したタグ（有名60＋すでに出した無名）を除外** → 残りを**優先順位を反映**して並べ、上位から20個ずつ出す。
- **採用: 案B（重要を優先）**
  - **重要タグ**を持つ作品だけをまず集め、その中の無名タグを上位に出す。
  - 足りなければ**優先1**のタグを持つ作品を混ぜ、さらに**優先2**… という**層**で無名タグを並べる。
  - 重要を押したものを優先的に考えたい、という方針に合わせる。
- **例外措置（偏りがある場合）**: 重要0・優先1だけ・優先2だけなどで無名タグの母数が少なくなる可能性は、**後からじっくり決める**。方針としては **「有名タグの最低個数」を決め、それに足りない場合のみ追加で質問する** 流れにしたい。

---

### ⑤ 結果を表示する

- **結果のアルゴリズム**: 選ばれたタグに**最終的な優先順位**をつけて、それに従い整合している作品を出す。難しくない想定。
- **最終優先順位**（相談まとめと同じ）:
  1. **重要な無名タグ**
  2. **重要な有名タグ**
  3. **無名タグ**
  4. **有名タグ**
- 作品スコア: 各作品が持つタグについて、上記4段階の重み（例: 重要無名=3, 重要有名=2.5, 無名=1.5, 有名=1）を掛けて合計。上位10作品などを表示する。
